# FreshScape Market POS System

A full-stack supermarket Point of Sale (POS) and Inventory Management System built with FastAPI, MySQL, and JavaScript.

## Features

- Authentication
- Product Management
- Inventory Management
- POS Checkout
- Customer Management
- Supplier Management
- Reports
- Dashboard

## Tech Stack

- FastAPI
- MySQL
- SQLAlchemy
- HTML
- CSS
- JavaScript
